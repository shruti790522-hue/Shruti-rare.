Put your own sticker / photo files in this folder (PNG, JPG, GIF, WEBP or SVG).
Then open js/main.js and set the paths in the STICKERS and MEMORIES blocks, e.g.

  birthday: "assets/stickers/birthday.png",
  wrong:    "assets/stickers/wrong-x.png",

Until you do, the site shows simple built-in drawn placeholders.
